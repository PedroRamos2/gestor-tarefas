# 📝 Gestor de Tarefas (Versão Base)

Este é um projeto simples de **Gestor de Tarefas** desenvolvido em **HTML, CSS e JavaScript puro**, com armazenamento no **LocalStorage**.  
Foi criado para treinar **frontend** e manipulação de dados no navegador.

---

## 🚀 Funcionalidades

- 🔐 Login simulado (usuário: `admin`, senha: `123`)  
- 📋 Listagem de tarefas  
- ➕ Criar tarefa (com nome, status e data de vencimento)  
- ✏️ Editar tarefa existente  
- ❌ Excluir tarefa  
- 🚪 Logout  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **LocalStorage** (simulação de banco de dados)
